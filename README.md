# Variational-Autoencoder-VAE-from-Scratch-using-Tensorflow
I implemented a Variational Autoencoder Architecture from Scratch using tensorflow on the CelebA dataset systematic latent variable manipulation and image generation.

Train a Variational Autoencoder (VAE) on any extensive image dataset.
Select at least three facial attributes, such as smiling, eye openness, and hairstyle and identify specific latent variables that influence each attribute.
For each, vary the corresponding latent dimension(s) while keeping others fixed, and generate image sequences that visually demonstrate how each attribute changes.

Important components:
VAE implementation.
Scripts for systematic latent variable manipulation and image generation.
For each attribute (smile, eye openness, hair), provide a grid/sequence of generated images showing the gradual change as you vary the corresponding latent variable.
Table clearly mapping each selected attribute to its discovered latent variable(s), with a brief description of how you identified each mapping (e.g., ablation, correlation with labels).
